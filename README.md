# Ana Elisa 1331 · Site Oficial de Campanha

> **"Minas quer mais dignidade, juventude e coragem no Congresso Nacional."**

Site oficial da candidatura de **Ana Elisa (1331)** a Deputada Federal por Minas Gerais (Eleições 2026), pela Federação Brasil da Esperança (PT / PCdoB / PV).

🌐 **Preview em Produção:** [https://felippejuan.github.io/ana-elisa-1331/](https://felippejuan.github.io/ana-elisa-1331/)

---

## 🏛️ Estrutura & Funcionalidades

O site foi construído com arquitetura estática leve, rápida, 100% responsiva e acessível, sem dependências externas de frameworks pesados:

1. **Header Fixo com Navegação Suave:** Menu mobile acessível e navegação por âncoras compensadas.
2. **Hero:** Apresentação da candidata, slogan oficial e destaque ao número de urna `1331`.
3. **História & Carta Manifesto:** Apresentação da trajetória de Ana Elisa e compromisso popular com Minas Gerais.
4. **Mapa Territorial de Minas Gerais (Interativo):**
   * Divisão por **8 macrorregiões** (Centro-Oeste, RMBH, Triângulo/Alto Paranaíba, Sul, Zona da Mata/Vertentes, Vale do Aço/Rio Doce, Norte e Vales).
   * Diagnóstico político e pautas prioritárias regionalizadas.
   * Botão inteligente para entrar no grupo regional de mobilização no WhatsApp.
5. **Compromissos:** Destaque à foto oficial com a Carteira de Trabalho e compromisso prioritário com o **Fim da Escala 6x1**, Educação Pública, Igualdade Racial e Cultura no Interior.
6. **Central de Materiais:** Cards controlados para download do santinho oficial, logotipo em alta resolução (PNG) e pacote oficial de figurinhas no Sticker.ly.
7. **Mobilização Direta (WhatsApp):** Formulário integrado que gera mensagem direta no WhatsApp, sem armazenamento de dados pessoais em servidores (Conformidade total com a LGPD).
8. **Rodapé & Transparência:** Dados jurídicos de prestação de contas, CNPJ da campanha e encarregado de privacidade de dados.

## 🚀 Como Executar Localmente

Não requer instalação de dependências ou build complexo:

1. Clone o repositório:
   ```bash
   git clone https://github.com/felippejuan/ana-elisa-1331.git
   cd ana-elisa-1331
   ```

2. Abra o arquivo `index.html` diretamente no seu navegador, ou utilize qualquer servidor HTTP local:
   ```bash
   # Exemplo via Python:
   python -m http.server 8000
   ```
   Acesse: `http://localhost:8000`
